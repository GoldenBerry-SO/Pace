# Notices

## Origin: impeccable

Pace was scaffolded from [impeccable](https://github.com/pbakaus/impeccable) (https://impeccable.style) by Paul Bakaus, used under Apache License 2.0.

Pace inherits impeccable's architecture: the skill router pattern, the multi-harness build system (13 harness output dirs), the Astro site shell, the CLI installer flow, and the plugin manifest format. Pace does NOT include impeccable's anti-pattern detector, Chrome extension, or live-mode browser tooling — those remain part of impeccable.

For frontend design work, pace defers to impeccable. The `npx pace skills install` flow offers to install impeccable alongside pace.
