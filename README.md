# pace

Company-wide skills for AI coding agents. One router (`/pace`), many commands across engineering, product, ops, marketing.

For frontend design, pace defers to [impeccable](https://impeccable.style); the installer offers to bring it along.

## Install

```bash
npx pace skills install
```

The installer asks whether you want impeccable installed alongside pace. Say yes if you do any frontend work.

## Use

```
/pace <command> [target]
```

Commands ship as they're authored. See `skill/SKILL.md` for the current router.

## Why pace

GoldenBerry's AI coding agents needed a shared vocabulary for how *we* work: not just design (impeccable has that) but engineering reviews, product specs, ops runbooks, marketing launches. Pace is the router for everything else.

Same install tech as impeccable. Different scope.
